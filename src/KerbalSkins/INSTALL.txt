Kerbal Skins @VERSION@
for Kerbal Space Program 1.12.x

The colour of the kerbals' skin: one for everyone, a different one for each kerbal, or your own choice for any one of them.

INSTALL
  Copy both folders in this download's GameData (Keystone and KerbalSkins) into your KSP's
  GameData folder, and start the game. Keystone is the base this mod stands on; one copy
  serves every mod that uses it. To remove the mod, delete the KerbalSkins folder.

USE
  Open the Keystone window: the keystone button on the game's toolbar, or Option-K on a
  Mac and Alt-K elsewhere. Then turn to Kerbal Skins and switch on "Change skin colours".

WHERE IT WORKS
  Made and tried on a Mac. Nobody has run it on Windows or Linux yet.

Everything else: https://github.com/IshiakiZ/ksp-kerbal-skins
