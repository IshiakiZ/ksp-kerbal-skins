Kerbal Skins @VERSION@
for Kerbal Space Program 1.12.x

The colour of the kerbals' skin: one for everyone, a different one for each kerbal, or your own choice for any one of them.

INSTALL
  This mod needs Keystone, the base it stands on, which is a separate download:
    https://spacedock.info/mod/4665/Keystone
  Copy Keystone's folder (Keystone) into your KSP's GameData folder, and the KerbalSkins
  folder from this download beside it, and start the game. Without Keystone the game does
  not load this mod. One copy of Keystone serves every mod that uses it. To remove this
  mod, delete the KerbalSkins folder.

USE
  Open the Keystone window: the keystone button on the game's toolbar, or Option-K on a
  Mac and Alt-K elsewhere. Then turn to Kerbal Skins and switch on "Change skin colours".

WHERE IT WORKS
  Made and tried on a Mac, and tried on Windows 11. Nobody has run it on Linux yet.

Everything else: https://github.com/IshiakiZ/ksp-kerbal-skins
